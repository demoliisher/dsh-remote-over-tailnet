# SSH 直连

DSH Go 除了走 DSH Remote 中继，还能用 SSH 直连一台已经开着的 DSH。ROT 把这条 SSH 服务放在 tailnet 地址上，因此电脑上不需要安装或开启 Windows 的 OpenSSH 服务，也不用开防火墙端口。对外端口随组网模式不同：系统 Tailscale 模式为 2222，内嵌节点模式为 22。

## 和 DSH Remote 中继的区别

| | DSH Remote 中继 | SSH 直连 |
| --- | --- | --- |
| 谁监听 | 中继服务器，tailnet 节点转发到它 | tailnet 节点自己 |
| 客户端填什么 | 服务器地址、账号、密码 | 地址、端口、账号、密码、DSH 登录令牌 |
| 能做什么 | 完整 DSH Remote 功能 | 只把连接转发到当前 DSH 实例 |

两套服务各自开关，可以只开其中一个，也可以都开。地址、账号、密码是同一套，面板顶部的「通用连接信息」都写在那里。

## 开启

中继服务的开关在「DSH Remote 本地中继服务」标题行右侧，SSH 的开关也在「SSH 服务」标题行右侧。只想用 SSH 直连时，中继服务可以一直关着。

1. 打开「插件 → Remote Over Tailnet → 远程设置」。
2. 顶部「通用连接信息」里确认地址、账号与密码。这两栏与 DSH Remote 共用，改完点这一块的「保存」。
3. 找到「SSH 服务」，打开标题行右侧的开关。系统模式端口 2222，内嵌模式端口 22。
4. 节点就绪后，这一块会显示 DSH 登录令牌与主机密钥指纹；中继没开时，节点只为 SSH 启动。

## 在 DSH Go 里填写

在「远程主机 → SSH 主机 → 添加 SSH 主机」里按下表填写，实例管理选「只连接」。

| DSH Go 字段 | 填什么 |
| --- | --- |
| 名称 | 随便取，例如「桌面」 |
| 主机 | 面板里的 tailnet 地址，形如 `<节点名>.<你的 tailnet>.ts.net` |
| 用户名 | 面板「通用连接信息」里的账号，默认 `owner@dsh.local` |
| 端口 | 系统模式 2222，内嵌模式 22（以面板「SSH 服务」显示为准） |
| 登录方式 | 密码，填「通用连接信息」里的密码 |
| 实例管理 | 只连接 |
| 远端 DSH 端口 | 填面板 SSH 服务里的「DSH 端口」数值；服务端只接受这个端口 |
| DSH 登录令牌 | 面板里的 DSH 登录令牌 |
| 工作目录 | 留空即可；只连接模式不做目录探测 |

首次连接会弹指纹核对，与面板里的主机密钥指纹一致时点「信任并连接」。

### 固定 DSH 端口

Desktop 每次启动的 Web 端口都不一样，「DSH 端口」右侧的「固定」按钮会记下当时那个端口。之后实例换了端口，插件在本机回环的同名端口上起反向代理，把连接转给新端口，客户端配置因此只需要做一次。端口没变时不起代理，固定端口上就是 DSH 自己。

固定之后按钮变成「解绑」。点击解除绑定，记录与代理一并撤掉，面板恢复显示当前实例的端口，客户端需要改回这个端口。

## 安全边界

- 只接受密码认证。账号密码与 DSH Remote 中继共用同一套，保存在 `$DSH_HOME/dsh-remote-over-tailnet/tailnet/credentials.json`（权限 0600）；在面板改完密码后 SSH 认证立即用新密码。
- 主机密钥首次生成后固定，指纹变化时客户端会拒绝连接；删掉 `ssh/host_ed25519` 等于更换主机身份。
- 认证通过后只放行 direct-tcpip 这一条通道，且请求的目标端口必须等于面板显示的 DSH 端口，对不上就拒绝。固定端口与当前实例端口不同时，那个端口上是插件在本机回环上起的反向代理，只转给当前的 DSH Web 端口；两者相同时拨到的就是 DSH 自己。远端 shell、命令执行、sftp、agent 转发一律拒绝，所以这条 SSH 做不了别的事。
- SSH 只在 tailnet 内可达，绑定在 tailnet 地址上，物理局域网无法访问。它和 DSH Remote 中继共用同一套节点与账号密码，两者各自开关，中继关掉不影响 SSH。

## 限制与排障

- 面板显示「当前运行的 DSH 引擎早于 SSH 模式」时，说明正在运行的 Host 进程还没加载这份代码，重启 DeepSeek Harness 后即可启用。
- 「托管启动」不支持：它要求远端有 POSIX shell 来执行 `sh -lc` 并常驻进程，Windows 上不做假 shell。
- SSH 端口随模式固定为 2222（系统）或 22（内嵌），在 tailnet 地址上被占用时开启会失败。固定的 DSH 端口如果已经被别的程序占用，反向代理起不来，面板会显示具体错误。
- DSH 登录令牌来自当前实例的启动链接。插件进程取不到这条链接时该栏留空，重启 DeepSeek Harness Desktop 后重试。
- 地址一栏只写主机名，不写 `ssh://` 前缀，也不带端口；端口填在单独的端口栏。
